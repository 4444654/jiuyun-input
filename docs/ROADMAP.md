# 玖云开发路线

## v0.1 原型

共享拼音候选核心、8 套双拼、可编辑键位、Web 体验、本地词库与词频、桌面 Rime 方案、原生 Android/iOS 工程。

## 下一阶段

1. 在真实 Rime、Android 与 iOS 环境编译和部署，验证切换、分号键、零声母、删除、密码、旋转、不同 App 输入。
2. 建立 Java/Swift 与 JavaScript 的同一组编码向量和候选对照测试，修正跨端排序差异。
3. 引入许可清楚的大词库，扩充单字与常用词，改进分句和重码排序。
4. 完善双拼新手引导、键位训练、方案兼容码、个人词库原生界面与可访问性。
5. 处理长按退格、大小写、Emoji、候选性能、内存限制与平板布局。
6. 建立正式版本签名、安装包和版本发布。跨端同步等联网能力需单独设计并由用户主动开启。

语音、手写、九宫格、辅助码与完整统计语言模型不在 v0.1 范围内。
